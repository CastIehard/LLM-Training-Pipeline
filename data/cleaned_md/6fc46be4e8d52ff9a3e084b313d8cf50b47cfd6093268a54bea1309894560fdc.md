### Externe Übersetzungstools

Wenn Sie eine Sprache vermissen, konnen Sie externe Übersetzungstools im Internet nutzen. Verwenden Sie eine Online-Übersetzungsplattform Ihrer Wahl. Wir empfehlen z.B. DeepL. Sie erhalten dort eine automatisch erzeugte Übersetzung unserer Informationen. Alternativ konnen Sie auch eine automatische Browser-Übersetzung verwenden. Fur diese Übersetzung konnen wir keine Verantwortung ubernehmen.

Vielen Dank, dass Sie unser Portal „Anerkennung in Deutschland“ nutzen.

**Indem Sie diesen Inhalt teilen, erkl aren Sie sich bereit, dass Ihre Daten an den jeweiligen Dienst ubermittelt werden und dass Sie die Datenschutzerklarung gelesen haben. **

## Unsere Tarife

Es können bis zu vier Räder gleichzeitig auf einem Account ausgeliehen werden. **Freiminuten gelten dabei nur für das erste Rad.**

**VAG_Rad:** Das Rad muss entweder an einer offiziellen VAG_Rad-Station oder innerhalb der Flexzonen sicher abgestellt werden. Nur so ist die Rückgabe kostenfrei. Wird das Rad außerhalb dieser Bereiche abgestellt, fällt eine **Vertragsstrafe von 20 Euro** an.

**VAG_eRad:** Das VAG_eRad darf ausschließlich an **VAG_Rad-Stationen** abgegeben werden. Erfolgt die Abstellung an einem anderen Ort, wird ebenfalls eine **Vertragsstrafe von 20 Euro** fällig.

**VAG_LastenRad:** Das VAG_LastenRad muss an seiner **Heimatstation** zurückgegeben werden, um die Rückgabe kostenfrei zu halten. Erfolgt die Abstellung an einem anderen Ort, wird eine **Vertragsstrafe von 50 Euro** erhoben.

Überprüfe vor der Rückgabe unbedingt in der **VAG_Rad-Karte der NürnbergMOBIL-App**, ob du dich innerhalb der Flexzone befindest.

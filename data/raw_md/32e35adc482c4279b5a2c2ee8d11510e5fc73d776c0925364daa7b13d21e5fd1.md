# Wohnungsgeberbestätigung

JavaScript is disabled. You can continue, but we recommend that you enable JavaScript so that you can use the following form comfortably and with all functions.

## Start

Zum Ausfüllen des folgenden Formulars benötigen Sie [Adobe® Reader®](http://www.adobe.de/products/acrobat/readstep2.html). Bitte laden Sie das PDF-Formular herunter, füllen es im Reader aus und speichern es ggf. lokal ab.

### So gehen Sie vor:

  1. Klicken Sie auf die Schaltfläche _Formular herunterladen_.
  2. Save the form as a PDF file on your computer and remember where you saved it. If your web browser does not ask where you want to save the PDF file, you will typically find it in a Downloads folder named "Wohnungsgeberbestätigung.pdf".
  3. Öffnen Sie die heruntergeladene Datei im Adobe Reader. Wir empfehlen, keine alternativen PDF-Viewer zu verwenden. Sie können den kostenlosen Adobe Reader von der [Webseite von Adobe](http://www.adobe.de/products/acrobat/readstep2.html) herunterladen.
  4. Füllen Sie das PDF-Formular im Adobe Reader aus und speichern es dann ab oder drucken es aus.
  5. Versehen Sie das Dokument mit Ihrer Unterschrift.
  6. Senden Sie das Dokument zusammen mit den ggf. erforderlichen Unterlagen an die zuständige Stelle.

# BayernPortal in Leichter Sprache

## Servus und Hallo im BayernPortal!

Das BayernPortal ist eine Seite im Internet.

Die Seite ist für alle Menschen in Bayern da.

Deshalb erklären wir hier die Seite in Leichter Sprache.

![](/images/leichteSprache/RGB-Bayern-Digitalisierung.png)

Es gibt viele verschiedene Ämter in Bayern.

Die Ämter arbeiten zusammen beim BayernPortal.

Sie sind für alle Bürgerinnen und Bürger da.

![](/images/leichteSprache/RGB-viele-menschen.png)

Das BayernPortal zeigt Ihnen alles,

was die Ämter für Sie tun können.

Zum Beispiel:

  * Wie können Sie Ihren Personal·ausweis bekommen?



![](/images/leichteSprache/RGB-Pass-Frau.png)

  * Wo können Sie Ihre Adresse ändern?



![](/images/leichteSprache/RGB-neue-adresse.png)

Sie brauchen zum Beispiel

einen neuen Personal·ausweis.

Sie müssen zu einem Amt gehen.

![](/images/leichteSprache/RGB-Amt.png)

Dann können Sie im BayernPortal

vorher vieles nachschauen:

  * Wo finden Sie das richtige Amt in Ihrer Stadt?
  * Was müssen Sie mitbringen?



![](/images/leichteSprache/RGB-Ortstecker.png)

  * Bis wann müssen Sie etwas machen?



![](/images/leichteSprache/RGB-Kalender.png)

  * Wie viel kostet es?



![](/images/leichteSprache/Geld.png)

  * Wo finden Sie den Antrag?

Können Sie den Antrag im Internet ausfüllen?

Kann Ihnen jemand am Telefon dabei helfen?




![](/images/leichteSprache/Antrag-ausfuellen.png)

## So benutzen Sie das BayernPortal:

Das BayernPortal ist eine Seite im Internet.

Die Seite ist vom Bundes·land Bayern für Sie.

was die Ämter in Bayern für Sie tun können.

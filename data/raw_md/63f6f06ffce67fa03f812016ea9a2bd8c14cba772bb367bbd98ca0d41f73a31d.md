# Termin beim Amt für Migration und Integration absagen oder verschieben

## Beschreibung

Sie haben vom Amt für Migration und Integration einen Termin erhalten und möchten ihn absagen oder verschieben.

##  Ablauf

Bitte nutzen Sie unseren Online-Dienst.

Teilen Sie uns online mit, welchen Termin Sie absagen möchten und begründen Sie Ihre Absage. Geben Sie an, ob Sie einen neuen Termin benötigen. Sie erhalten dann einen Brief mit einem neuen Termin.

##  Einfach online machen

        * [ Termin beim Amt für Migration und Integration absagen oder verschieben (Online-Dienst) ](https://meinkonto.nuernberg.de/intelliform/forms/n/335_mi/330_ep_d_terminabsage/index "Interner Link: Termin beim Amt für Migration und Integration absagen oder verschieben \(Online-Dienst\)")

##  Voraussetzungen

        * Sie haben einen Antrag beim Amt für Migration und Integration gestellt.
        * Sie haben einen Brief mit einer Termineinladung erhalten.
